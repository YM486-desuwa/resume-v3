- 线上地址（部署后）：`https://ym486-desuwa.github.io/resume-v3/`
- 在线小游戏作品：https://brilliant-mousse-a52542.netlify.app/ （《霓虹战域 NEON STRIKERS》）

## 文件结构

```
├── index.html        全部页面（内联 CSS/JS，单文件）
├── game-cover.jpg    游戏作品封面（实机截图）
└── assets/
    ├── tx.jpg        头像
    ├── jin.jpg       家教辅导证明
    ├── sx.jpg        社会实践证明
    └── zs.jpg        AI 技能认证证书
```

## 部署（GitHub Pages）

1. 仓库 Settings → Pages
2. Source 选择 `Deploy from a branch`，Branch 选 `main` + `/ (root)`
3. 保存后等待 1~2 分钟生效

> 本仓库独立于旧站 `resume` 仓库，两者互不影响。
